# 素材來源與授權

本站使用的非自製素材,來源與授權整理於此(呼應 D6 來源透明原則)。

## 篆書字形 `public/img/seal/`

- **內容**:十二生肖、干支(天干地支)、「全」、以及部分變體/本字動物(貓、猪、豕、犬、它)
  的**小篆**字形 SVG;另存少數動物簡圖於 `public/img/seal/icon/`。
- **原始來源**:**《說文解字》**(東漢·許慎,約西元 100 年)的小篆字形。原典屬**公有領域**。
- **取得管道**:經 [zi.tools 字統网](https://zi.tools/) 的公開 API(`/api/zi/<字>` 的 `swjz.glyph`,
  swjz = 說文解字)取得其向量化 SVG,CDN 路徑為 `…/swjz/<id>.svg`。
- **重建方式**:`uv run scripts/fetch_seal_svgs.py`(冪等)。
- **授權判斷**:字形本體源自公有領域的《說文解字》小篆,屬合理使用;感謝 zi.tools 的整理與向量化。
  若日後 zi.tools 對其向量檔另有明確授權要求,再行調整或改用其他公有領域字形來源。
